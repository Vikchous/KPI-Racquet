# KPI-Racquet

> **Racquet** - візитка-сайт тенісного клубу: оренда кортів, клубні абонементи, заняття з тренером, дитячі групи з тенісу та організація турнірів.

 **Роботу виконали (гр. КА-44):** 
Онашко Вікторія, Мельниченко Наталія, Шкіро Віолетта.

---

##  Структура каталогів та файлів

###  Директорії
*  **`css/`** - стилі сайту (детальніше — у розділі «Організація стилів»)
*  **`images/`** - графічні елементи та фотовміст
*  **`js/`** - `main.js`: стрілки каруселей, вкладки правил, закриття бургер-меню після переходу

### Основні сторінки
*  **`index.html`** - головна сторінка сайту
*  **`about.html`** - сторінка «Про клуб»
*  **`kids_tennis.html`** - сторінка «Дитячий теніс»
*  **`news.html`** - стрічка новин та анонсів

###  Панель адміністратора
*  **`admin_login.html`** - форма автентифікації адміністратора 
*  **`admin_dashboard.html`** - кабінет управління замовленнями та новинами

## Оформлення та адаптація

### Організація стилів
Усі сторінки підключають **один** файл `css/style.css`, який збирає модулі через директиву `@import`:

| Файл | Призначення |
|------|-------------|
| `normalize.css` | вирівнювання стандартних стилів між браузерами |
| `base.css` | брендбук: шрифти (Abel, Abhaya Libre), кольори, посилання, шапка, банери, футер |
| `components.css` | компоненти: кнопки, картки, акордеон, модальні вікна, поля форм і стани валідації |
| `layout.css` | макет сторінок: сітки Grid, ряди Flexbox, каруселі, бургер-меню, медіазапити |
| `admin.css` | стилі панелі адміністратора |

```css
@import url("normalize.css");
@import url("base.css");
@import url("components.css");
@import url("layout.css");
```

### Застосовані технології
* **CSS Grid** - сітка типів кортів (3 колонки), блоки «фото + текст» на головній і в «Про клуб», колонки «Ціни / Послуги», вкладки правил, галерея дитячого тенісу, сітка новин (`repeat(auto-fill, minmax(...))`), розкладка заголовка й стрілок каруселі тренерів (`grid-template-areas`).
* **Flexbox** - шапка та навігація, картки в банері, футер, стрічки каруселей, статистика клубу, FAQ «драбинкою», картки новин.
* **Медіазапити (`@media`)** - три точки зламу:
  * `≤ 1024px` (планшет) - бургер-меню, менше колонок, акордеон на всю ширину;
  * `≤ 767px` (телефон) - одна колонка, каруселі показують 1 картку з краєчком наступної, вкладки правил стають горизонтальною стрічкою, футер стовпчиком;
  * `≤ 420px` (вузькі телефони) - менші відступи та шрифти;
  * `prefers-reduced-motion` - вимкнення анімацій для користувачів, які їх не бажають.
* **Адаптивне бургер-меню** - реалізоване на чистому CSS (прихований `checkbox` + `label` і селектор `:checked ~ .main-nav`), тому працює навіть без JavaScript; іконка анімовано перетворюється на хрестик.
* **Scroll Snap** (`scroll-snap-type`) - каруселі тренерів, послуг і фото кортів гортаються свайпом; стрілки прокручують стрічку через `js/main.js`.
* **`aspect-ratio` + `object-fit: cover`** - однакові пропорції фото незалежно від розміру вихідних зображень.
* **HTML5-валідація форм** - `required`, `type="email"`, `type="tel"` + псевдокласи `:valid` / `:invalid` для підсвічування полів.
* **Popover API** — модальні вікна бронювання, абонементу, запису дитини та новин без JavaScript.

### Перевірені розміри екрана
375 px (iPhone), 768 px (iPad), 1440 px (ноутбук/ПК) - горизонтальної прокрутки немає на жодній сторінці.
