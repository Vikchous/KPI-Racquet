# KPI-Racquet

Racquet - візитка-сайт клубу, який спеціалізується на наданні послуг відносно тенісу: аренда кортів, абонементи, заняття з тренером, дитячі групи з тенісу. Також організація спеціалізованих івентів і турнірів. Сайт складається з таких сторінок: головна сторінка (користувач дізнається коротко про клуб, має доступ до інформації щодо тренерський склад, ціни, абонементи та послуги), про клуб (користувач дізнається детальніше про клуб: кількість кортів, правила і історію), дитячий теніс (інформація щодо дитячої секції з тенісу), новини (користувач дізнається про найближчі івенти, турніри й інше).

Роботу виконали: Онашко Вікторія, Мельниченко Наталія, Шкіро Віолетта.

Структура проєкту:
index.html - головна сторінка;
about.html - сторінка “Про клуб”;
kids_tennis.html - сторінка “Дитячий теніс”;
news.html - сторінка “Новини”;
admin_login.html - захищена сторінка входу (/admin/login) для безпечної автентифікації адміністратора клубу в системі;
admin_dashboard.html - робочий кабінет адміністратора (/admin/dashboard) для моніторингу замовлень послуг клубу та керування контентними публікаціями сайту;
